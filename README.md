# Description

A repo for managing my linux and windows dotfiles. Stow is used to automatically manage symlinks in linux while .ps1 script used in windows with relative path to create symlinks there

# Windows

```
Windows
└───.config
    ├── fastfetch
    ├── Komorebi
    ├── wezterm
    └── yasb
```
